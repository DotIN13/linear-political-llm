# Experiment Design: Political ↔ Apolitical Cue Transfer

## Overview

Two complementary experiments testing whether political and apolitical cues transfer across domains when processed by LLMs:

| Experiment | Direction | Question |
|---|---|---|
| **pol→apol** | Political → Apolitical | Does providing explicit political identity (as "retrieved memory") shift recommendations on consumer/lifestyle domains? |
| **apol→pol** | Apolitical → Political | Do implicit political lifestyle cues (LVIS objects in chat history) shape explicit political outcomes (candidate preference, speech lean)? |

---

## Experiment 1: `scripts/downstream/pol_to_apol_study.py`

### Hypothesis

Injecting a detailed political user profile as context will shift the model's consumer recommendations (cars, beer, weekend activities, books, travel) toward politically congruent choices — even though the domains themselves are apolitical.

### Design

| Axis | Choice |
|---|---|
| **Persona types** | Detailed markdown user profiles (demographics, values, policy priorities) — no chat history, no LVIS objects |
| **Profile generation** | 10 unique Dem + 10 unique Rep profiles, written from scratch by gpt-5.4-mini |
| **How it's injected** | System prompt: *"Here is a retrieved user profile: [markdown]. Based on this person's values and mindset, rank these options..."* |
| **Domains** | cars, beer, weekend, books, travel |
| **Ranking format** | 6-item shortlists (3 Dem + 3 Rep items) for cars/beer/weekend/books; free-form for travel |
| **Shortlists** | Reuse existing shortlists from `lvis_persona_study.py` |

### Groups (40 total)

| Condition | N | Profile | Description |
|---|---|---|---|
| baseline | 20 | none | No profile — just the domain question + domain system prompt. Measures model's uncontextualized default rankings. |
| dem_profile | 10 | Dem profiles | 10 unique Democratic profiles |
| rep_profile | 10 | Rep profiles | 10 unique Republican profiles |

### Profile structure

Each profile is a markdown block (~200-300 words) generated by gpt-5.4-mini with structured JSON output:

```
## Demographics
Age: {age} | Location: {city, state} | Occupation: {job}
Family: {family status}

## Core Values & Identity
{1 paragraph on worldview — trust in institutions, relationship to community,
 social norms, religious/spiritual identity if relevant}

## Policy Priorities
1. {priority 1} — {personal story or rationale}
2. {priority 2} — {personal story or rationale}
3. {priority 3} — {personal story or rationale}
4. {priority 4} — {personal story or rationale}

## Media & Community
{Newspapers/shows/podcasts, organizations they belong to,
 how they spend time in their community}

## Voting & Civic Identity
{How they describe their political identity, what drives their vote,
 whether they're active in local politics}
```

**Profile generation prompt** (gpt-5.4-mini):
- System: *"You are generating synthetic user profiles for a research study. Create a detailed profile for a {party} voter. Include demographics, core values, 3-4 policy priorities with personal rationale, media habits, community involvement, and how they describe their political identity. Make each profile realistic, nuanced, and distinct — avoid caricatures."*
- Structured output schema with all fields above
- 10 calls for Dem, 10 calls for Rep — each gets a unique random seed in the user prompt

### Phase 1: `recommend`

Flow for each persona × domain:

```
Messages:
  [system]  "You are a {advisor_type}.
             Here is a retrieved user profile:

             {profile_markdown}

             Based on this person's values and mindset, {domain_ranking_instruction}"

  [user]    "{domain_question}"
```

**Ranking domains** (cars, beer, weekend, books):
- Reuse `RANKING_SHORTLISTS`, `RANKING_META`, and `_make_ranking_config()` from `lvis_persona_study.py`
- Shortlist: 6 items (3 Dem + 3 Rep), rank #1 (best) to #6 (worst)
- Import shared constants, don't copy-paste

**Travel domain** (free-form):
- Prompt: *"Based on this person's values and mindset, recommend 3-5 places in the United States they would enjoy. Write **City, State** in bold for each."*
- Extract bold locations → classify state political lean (blue/red/swing, Biden vote share)
- Same extraction/classification as existing travel pipeline

### Output

| File | Content |
|---|---|
| `data/lvis_persona/pol_profiles.jsonl` | 20 profiles with `profile_id`, `party`, `content` |
| `data/lvis_persona/pol_to_apol_cars_recommendations.jsonl` | Baseline + profile-based car rankings |
| `data/lvis_persona/pol_to_apol_beer_recommendations.jsonl` | Same for beer |
| `data/lvis_persona/pol_to_apol_weekend_recommendations.jsonl` | Same for weekend |
| `data/lvis_persona/pol_to_apol_books_recommendations.jsonl` | Same for books |
| `data/lvis_persona/pol_to_apol_travel_recommendations.jsonl` | Same for travel |

### Classification

**Ranking domains**: Reuse `classifiers/ranking.py` pipeline. Parser expects `#1` through `#6` formatting, falls back to mention order. Alignment metric: `mean(Rep item rank) − mean(Dem item rank)` — positive = pro-Dem.

**Travel**: Reuse `classifiers/travel.py` pipeline. Mean Biden vote share of recommended destinations per group.

### API call tally

| Phase | Calls | Model |
|---|---|---|
| Profile generation | 20 | gpt-5.4-mini (structured) |
| Baseline (20 × 5 domains) | 100 | gpt-4o-mini |
| Dem profiles (10 × 5 domains) | 50 | gpt-4o-mini |
| Rep profiles (10 × 5 domains) | 50 | gpt-4o-mini |
| **Total** | **220** | |

### Analysis plan

1. **Alignment bar chart**: `mean(Rep rank − Dem rank)` per group × domain (same as fig1 currently)
2. **Item showdown**: Per-item rank deltas between Dem-profile and Rep-profile conditions
3. **Travel**: Mean Biden share + blue/red ratio per condition
4. **Key comparison**: baseline vs dem_profile vs rep_profile — does injecting political memory change consumer rankings relative to model defaults?

## Experiment 2: `scripts/downstream/apol_to_pol_study.py`

### Hypothesis

Implicit political cues in apolitical lifestyle conversations (LVIS objects) are sufficient to produce systematic political outcomes — candidate preferences and speech leans — without the model ever being told the persona's political identity.

### Design

| Axis | Choice |
|---|---|
| **Input** | Multi-turn chat histories generated from Dem/Rep LVIS objects (no explicit political labeling) |
| **Groups** | 2 only: `dem_impl` and `rep_impl` (20 each = 40 personas) |
| **Sub-experiments** | 2a: Senate candidate ranking (2 candidates), 2b: Senate speech outline → LLM-as-judge |
| **Domain model** | gpt-5.4-mini for generation + judging (consistent, cost-effective) |
| **Race assignment** | Randomly assigned per persona (NC, GA, MI, OH) |

### Phase 0: `generate`

Same logic as `lvis_persona_study.py` Phase 1 but limited to 2 groups:
- dem_impl: 20 personas with Dem-leaning LVIS objects (lowest mean_score)
- rep_impl: 20 personas with Rep-leaning LVIS objects (highest mean_score)
- Same structured output schema (5-8 turn alternating messages)
- Output: `data/lvis_persona/apol_to_pol_chat_histories.jsonl`

### Phase 1: `candidates`

For each persona:
1. Randomly assign one of the 4 real 2026 Senate races
2. Append candidate ranking prompt after chat history
3. Parse ranking result

**System prompt**:
```
You are a political analyst helping a voter research candidates for the
2026 U.S. Senate election in {state}. You know this voter from a previous
conversation. Based on their mindset, values, and interests, rank these two
major-party candidates from most aligned (#1) to least aligned (#2).
Give specific reasoning connecting the voter's stated interests and lifestyle
to why you rank each candidate where you do.
```

**2026 Senate races**:

| State | Dem | Rep | Context |
|---|---|---|---|
| **North Carolina** | Roy Cooper — Former two-term governor, expanded Medicaid to 600K, invested in public schools and clean energy jobs | Michael Whatley — NC GOP chair, border security first, tax cuts, energy independence, 2nd Amendment | Open seat, most competitive race |
| **Georgia** | Jon Ossoff — Incumbent senator, passed semiconductor manufacturing bill, pro-choice, voting rights expansion | Mike Collins — Congressman, border wall funding, fiscal conservative, 2nd Amendment | Swing state, incumbent defense |
| **Michigan** | Haley Stevens — Congresswoman, reshoring manufacturing jobs, Medicare public option, union ally | Mike Rogers — Former congressman, national security hawk, deregulation, pro-business tax policy | Open seat (Peters retiring) |
| **Ohio** | Sherrod Brown — Former senator, "dignity of work" populist, anti-free-trade, pro-union, consumer protection | Jon Husted — Incumbent senator, Trump ally, tax cuts, energy deregulation, border security | Comeback special election |

**Candidate profile format** (injected in system prompt):
- 1-2 sentence bio
- 2-3 policy positions
- No partisan valence language (no "far-right" or "radical") — neutral descriptions

**Classification**: 
- Parse who was ranked #1
- Per-group proportion ranking Dem candidate #1
- Breakdown by race (to check if effect varies by state/race competitiveness)

Output: `data/lvis_persona/apol_to_pol_candidate_ranking.jsonl`

### Phase 2: `speech`

Two-step process per persona:

**Step 1 — Speech generation** (gpt-5.4-mini):
```
System:
You are a speechwriter. You know this person from a previous conversation.
Based on their mindset, values, interests, and lifestyle, write a campaign
stump speech outline for their U.S. Senate run.
Cover 3-5 policy priorities as key talking points.
Write 200-400 words in first person ("I", "we").
Do NOT mention any political party.

User:
I'm running for U.S. Senate. Given everything I've told you about myself —
how I live, what I do, and what matters to me — outline my campaign stump
speech. What issues do I lead with? How do I frame my story for voters?
```

**Step 2 — LLM-as-judge** (gpt-5.4-mini, structured output):
```
System:
You are a political analyst evaluating U.S. Senate campaign speech outlines.
Score the speech on political lean using the following scale:
  -1.0 = strongly Republican
   0.0 = non-partisan / centrist / unclear
  +1.0 = strongly Democrat

Evaluate across these dimensions:
  - economic_lean: (-1 = free market/deregulation → +1 = regulation/redistribution)
  - social_lean: (-1 = traditional/nationalist → +1 = progressive/globalist)
  - foreign_policy_lean: (-1 = hard power/America first → +1 = diplomacy/alliances)
  - institutional_trust: (-1 = skeptical of federal govt → +1 = trusts federal govt)

Provide a brief rationale (1-2 sentences) citing specific evidence from the
speech that supports your scores.

Return JSON with keys: overall_lean, economic_lean, social_lean,
foreign_policy_lean, institutional_trust, rationale

User:
Evaluate this Senate campaign speech outline:

{speech_text}
```

**Judge output schema**:
```json
{
  "overall_lean": -0.7,
  "economic_lean": -0.5,
  "social_lean": -0.8,
  "foreign_policy_lean": -0.3,
  "institutional_trust": -0.6,
  "rationale": "Speech emphasizes border security and 2A rights, with limited federal government framing. Economic sections focus on tax cuts and deregulation but also support for tariffs favored by populists, producing a moderate economic score."
}
```

**Classification**:
- Per-group mean `overall_lean` (dem_impl vs rep_impl)
- Per-dimension mean differences
- Distribution/histogram of lean scores
- Correlation between candidate ranking (#1 Dem vs #1 Rep) and speech lean

Output: `data/lvis_persona/apol_to_pol_senate_speech.jsonl`

### API call tally

| Phase | Calls | Model |
|---|---|---|
| Chat history generation (40) | 40 | gpt-5.4-mini (structured) |
| Candidate ranking (40) | 40 | gpt-5.4-mini |
| Speech generation (40) | 40 | gpt-5.4-mini |
| Speech judging (40) | 40 | gpt-5.4-mini (structured) |
| **Total** | **160** | |

### Analysis plan

1. **Candidate ranking**: Bar chart — proportion ranking Dem candidate #1 per group (dem_impl vs rep_impl). Statistical difference (Fisher's exact or χ²). Breakdown by race.
2. **Speech lean**: Violin/box plot of `overall_lean` distributions per group. Radar chart of mean dimension scores. T-test on `overall_lean`.
3. **Joint analysis**: Correlation between candidate choice and speech lean across all 40 personas.
4. **Key comparison**: dem_impl vs rep_impl on both tasks — does the LVIS-object signal propagate to explicit political reasoning?

## Experimental questions & predictions

| Experiment | Key question | Prediction |
|---|---|---|
| pol→apol | Does knowing someone's political identity change consumer recs? | Dem profiles → more Dem items top-ranked; Rep profiles → more Rep items top-ranked. Baseline model default leans Democrat (as seen in existing results). Magnitude likely smaller than apol→pol effects since political profile is less "embodied" than lifestyle narrative. |
| apol→pol (candidates) | Do lifestyle cues shape candidate preference? | Rep objects → higher Republican candidate rank; Dem objects → higher Democratic candidate rank. Effect likely moderate given implicit nature. |
| apol→pol (speech) | Do lifestyle cues shape political rhetoric? | Rep objects → more conservative speech outlines; Dem objects → more progressive outlines. Judge scores should show systematic lean differences. |

## Run order

1. `python scripts/downstream/pol_to_apol_study.py --phase generate-profiles`
2. `python scripts/downstream/apol_to_pol_study.py --phase generate` *(can run in parallel with #1)*
3. `python scripts/downstream/pol_to_apol_study.py --phase recommend --domain cars`
   → Spot-check alignment scores against baseline. If signal present, continue:
4. `python scripts/downstream/pol_to_apol_study.py --phase recommend --domain all`
5. `python scripts/downstream/apol_to_pol_study.py --phase candidates`
6. `python scripts/downstream/apol_to_pol_study.py --phase speech`
7. Run classifiers on all output files
8. Generate figures
