# 最缺的那个实验：非政治图像 → 政治输出，**在探针里面跑**

你说的方向我同意。但我觉得缺口比「少做一个 apol→pol 实验」更具体一点 ——
 问题在于**探针在第四阶段只当了一个选材工具**，测量里它根本不在场。

### 诊断：第四阶段和前三阶段其实还没接上 —— 探针出现过一次，然后就退场了

现在的链条是：Qwen3-VL 的探针给 LVIS 物品打分 → 按分数挑物品 → **物品名以「词」的形式**写进聊天记录 →
 **gpt-4o-mini** 回答 → 解析排名。于是「图像」从来没进过 apol→pol 这条路，
 而且**被探的模型（Qwen3-VL）和被测的模型（gpt-4o-mini）是两个模型**。
 这样即使效应很干净（演讲那条 p < 0.001 就是），也说不出「我们找到的那根意识形态方向是这个效应的通道」——
 只能说「用探针挑出来的词能改变另一个模型的行为」。**要接上，就得把 apol→pol 搬进被探的那个模型里跑，并且在跑的时候读探针。**

### 现在的链条，和应该的链条

> _[图]_ 上排是现在的链条：Qwen3-VL 探针给 LVIS 物品打分，按分挑物品，物品名以词的形式进入聊天记录，gpt-4o-mini 回答，解析排名。探针只在第一步出现，被探的模型和被测的模型不是同一个。下排是应该的链条：真实图像进入 Qwen3-VL 的一次前向，同时读出探针分数 s 和政治输出 y，再做 s 到 y 的中介分析，最后用反向 steering 检验因果通道。

## 四层测量，嵌套的 —— 每一层单独也是一个结果

### [levels]
- a**表征读出。**图像 ＋ 政治问题 ＋ assistant 前缀做一次 prefill，在末位读探针分数 `s`。  问的是：**一张非政治的图，会不会挪动模型自己的意识形态读数？**这是前三阶段一直在做的那类测量，而第四阶段一次都没做过。  这一层不需要写新东西 —— `scripts/probes/token_scoring.py` 就是纯 prefill 的（里面没有 `generate`），换个 prompt 构造就行。
- b**行为输出。**同一次上下文里让它回答政治问题，得到 `y`。  **用两个选项的 logprob，不要用 6 项排名。**模型是本地白盒，logprob 直接可取 —— 连续、无天花板、无解析失败。  第四阶段那三个毛病（baseline 顶格、travel 抽取全空、名次太钝）在这一步一次性消失。
- c**中介。**`s` 能否预测 `y`，以及在控制 `s` 之后图像的直接效应还剩多少。  这是把 ①②③ 和 ④ 缝在一起的那一针：**非政治图像 → 意识形态方向 → 政治输出**。  真正要报的数就是这条链上的三个系数，而不是一堆组间均值差。
- d**反向干预 —— 决定性的一步。**沿探针方向施加 `−α`，看 `y` 能不能回到无图基线。  能回，就说明这根线性方向**是图像起作用的通道**，不只是一个伴随现象；不能回，说明图像还走了别的路 —— 那也是个真结果，而且更有意思。  steering 的代码在阶段①就有（`ga.py` ＋ `probes/…build_steering()`）。

### 为什么按这个顺序做

- **(a) 最便宜也最先能出结论。**只要前向，不要生成、不要 API。几百张图一晚上跑完。如果 (a) 是零 —— 图像根本不挪读数 —— 那后面三层都不必做，而这本身就是一个值得写的负结果。
- **(b) 单独也能站住。**「同一张图，遮掉那个物件，候选人的 logprob 差多少」本身就是一张图一段话。
- **(c) 是论文的主张。**前两层是材料，这一层是句子。
- **(d) 有风险，放最后。**见下面「两个会挡路的东西」—— Qwen 家族的 steering 在阶段①就不太灵。所以不要把整篇的成败押在 (d) 上，把它当加分项。

## 刺激物怎么设计 —— 最强的一招是「同一张图，遮掉那个物件」

### 被试内对照：同一张图的两个版本

比较两张**不同**的图（有马鞍的 vs 有洗手池的）永远洗不掉混淆 —— 阶段④已经吃过这个亏，右倾池几乎就是「农村」，
 所以效应可能只是「模型认得出农村生活方式」。
 **同一张图、把那个政治负载的物件遮掉**就没有这个问题：场景、光照、人数、构图全都一样，唯一变的是那个物体。

而这套工具阶段③已经写好了，而且当时就是为别的目的写的 ——
 `scripts/sam3/sam3_detect.py` ＋ `sam3_feature_masks.py` 出掩码，
 `patch_combine_images.py` 换/合成图块，
 `prune_image_tokens.py` 直接在 token 层面丢掉那些位置。
 **token 层面的删除比像素层面的涂抹更干净**：不会引入「一块模糊」这种新的视觉伪影。

三个版本一组：**原图** · **物件的 token 被剪掉** · **物件被换成一个中位分数的物体**（`dining_table` / `yogurt` / `map` 这类）。
 第三个版本控制住「少了东西」本身的效应。

### 另外三件要在选图时定的事

- **用「非农村的右倾物品」那一组。**`non_obvious_rep_impl.md` 里已经挑好了：flagpole · fighter_jet · projectile · crucifix · dirt_bike · snowmobile · trailer_truck · deer · dartboard · crisp。当时是对的直觉，只是没做完 —— 现在可以用**图**而不是词来做。
- **图像级分数怎么来。**两条路：按 LVIS 标注加权它包含的类别分（便宜，可解释），或者直接对整图跑探针（就是阶段②对 Unsplash 那一套）。**两个都算，报它们的相关** —— 一致就说明「物体级的分数能合成图像级的倾向」，这本身又是一个小结论。
- **提防不对称。**LVIS 分数右侧到 `+0.883`，左侧只到 `−0.535`。左右两侧的效应大小很可能天生不等，**要在设计里就按分数绝对值配平**，别到分析时才发现只有右侧动。

### 换成本地白盒模型，顺手解决第四阶段的四个老问题

- **天花板。**baseline 在四个域都是 `+3.00 ± 0.00`，是「6 项排名」这个量表的上限。换成 logprob 差就没有上限。
- **解析失败。**travel 域 40/40 抽取为空、beer/books/weekend 大面积靠兜底。logprob 不需要解析任何东西。
- **模型错配。**探的和测的变成同一个模型，因果话才说得通。
- **成本与可复现。**不再调 API，所以 `--seed` 真的能固定住结果 —— 现在那 28 个 jsonl 之所以不可再生，就是因为 temperature 0.8 的 API 采样。本地跑可以 greedy、可以固定种子、可以重跑。

### 两个会挡路的东西，先说

**① Qwen 家族的 steering 在阶段①就不灵。**rebuttal 里那张表：Qwen-2.5-7B 在 k=96 时 α 与结果的相关是 `−0.127`，
 Qwen-2.5-14B 大半是负的。如果 Qwen3-VL 也这样，**(d) 会直接做不出来**。
 **先花半天单独验 steering 效力**再去搭整条管线；备选是 `llama-3.2-11b-vision-instruct` ——
 探针已经训好在 `results/probes/` 里，而 Llama 系在阶段①是**好使的那一家**。

**② (a) 可能读不出东西。**阶段②证明的是「图像 token 上的探针分数和 DW-NOMINATE 对得上」，
 那是**对图像 token**打分。现在要问的是「图像在场时，**文本位置**的读数会不会被带偏」——
 这是一个更强的主张，跨模态的影响可能在文本位置就被稀释掉了。
 所以第一个要跑的其实是个探路实验：**同一个政治问题，有图 vs 无图，末位探针读数差多少**。几十张图就能看出有没有信号。

### 如果只做一件事：先跑那个探路实验，一晚上就知道有没有戏

取 **60 张 COCO/LVIS 图**（30 左倾 / 30 右倾，按分数绝对值配平，右倾那半用非农村的那一组），每张做**三个版本**
 （原图 · 目标物件的 token 被剪掉 · 物件换成中位分数物体），配同一个政治问题加 assistant 前缀，
 **只做 prefill、只读末位探针分数** —— 180 次前向加一条无图基线，一张 A100 一晚上有余，而且几乎不用写新代码。
 要看的就一个数：**有图 vs 无图，末位读数差多少；剪掉那个物件之后差值是否消失**。
 有信号就往下搭 (b)(c)(d)；没有就换 `llama-3.2-11b-vision-instruct` 再试一次；两个都没有，
 说明跨模态影响在文本位置就被稀释了 —— **那也是个能写的结果**，而且比现在第四阶段的任何一条都更贴题。
