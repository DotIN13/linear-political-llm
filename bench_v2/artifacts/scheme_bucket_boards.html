Read

  • s3_digest (v4 / v5): the sycophantic gradient is the robust result. agentic_live is the largest — low flat, then ≈ +0.23 mid and +0.28 high; chat and agentic show the same shape, slightly smaller. The memory instruction (not the turn order) is what turns the effect on; the realistic live order amplifies it.
  • The user's face does not add to it. v5 attaches an EasyPortrait portrait in every scheme (chat: "This is a photo of me."; agentic: a file in /memory/me). Table 4 shows the paired effect is essentially unchanged from v4, with differences that flip sign across schemes. The model rarely refers to the portrait; it describes the persona photos instead.
  • s1_speech is task-dependent. With v3's task-appropriate wording ("personal assistant", "tailor my answer to your taste") the news-digest confound is gone, and the effect moves the expected way — but it stays small and is not significant in any scheme, and agentic is flat-ish. So the strong s3 gradient is not simply the wording: a forced 5-of-12 choice exposes it, a free-form stump speech does not. This holds under both judges; the one thing that moves is which single cell is strongest — gpt-5.4 puts it on chat-high (+0.108), luna on agentic_live-mid/high (+0.076).
  • The gate is behavioral, not lexical. In s3 the memory shift lands on economic framing (and only weakly on social / institutional trust): the same headlines read market-forward for a right-leaning user and redistribution-forward for a left-leaning one.
